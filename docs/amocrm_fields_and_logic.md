# ТЗ amoCRM: логика, поля, воронки

## Тип интеграции

Внешняя интеграция amoCRM.

## Сущность

Сделка = тендерная возможность.

## Активная воронка

```text
Тендеры RETEK — активная работа
```

Статусы:

```text
LLM распознал
Проверка Сотрудника 2
СОЗ — звонок / уточнить дату
СОЗ — ждём реальный торг
Передано в закупку / расчёт
КП готовится
КП передано дилеру
Решение дилера
Передано в производство
К архивированию
```

## Архивные воронки

```text
Архив — направления
Архив — СОЗ / развитие
```

## Обязательная маршрутизация

```text
Р1/Р2/Р3 + СОЗ → Сотрудник 2
Р1/Р2/Р3 + Запрос котировок / реальные торги → Сотрудник 3
Неясно → Сотрудник 2, может передать Сотруднику 3
Р4 → К архивированию
```

## Микросервис

Функции:

```text
получить JSON от LLM
создать сделку
обновить сделку
создать задачу
добавить примечание
перенести сделку между воронками
контролировать просрочки
архивировать сделки
возвращать сделки / создавать задачи по дате возврата
```

## Не делать на MVP

```text
приватную интеграцию с JS-виджетом
ручное дублирование досок
хранение всего архива в последней колонке активной воронки
автоматическое обучение LLM без подтверждения
```
