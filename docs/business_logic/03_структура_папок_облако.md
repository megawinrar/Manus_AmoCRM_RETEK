# Структура папок в облаке для ежедневного сбора торгов

## Контекст

Первый этап системы — не CRM, а дисциплина ежедневного сбора документов.

Сотрудник 1 должен каждый день находить торги, скачивать документы и складывать их в облако. Он не обязан заполнять CRM или классифицировать тендеры.

---

# 1. Главная папка

Рекомендуемое название главной папки:

```text
Торги
```

Внутри можно сделать структуру по годам и месяцам:

```text
Торги/
    2026/
        06_Июнь/
            06_06_2026/
            07_06_2026/
            08_06_2026/
```

Если нужно ещё проще, можно начать так:

```text
Торги/
    06_06_2026/
    07_06_2026/
    08_06_2026/
```

Главное правило: **каждый день должна быть папка с датой**.

---

# 2. Формат папки дня

Рекомендуемый формат:

```text
ДД_ММ_ГГГГ
```

Пример:

```text
06_06_2026
```

Или расширенный формат:

```text
2026_06_06
```

Лучше использовать один формат постоянно.

---

# 3. Если торгов нет

Если сотрудник 1 за день не нашёл подходящих торгов, всё равно нужно создать папку или файл-отметку:

```text
06_06_2026_торгов_нет
```

или внутри папки дня файл:

```text
торгов_нет.txt
```

Содержание файла:

```text
Дата: 06.06.2026
Проверено: да
Подходящих торгов не найдено
Сотрудник: [имя]
```

---

# 4. Папки внутри дня

На старте не нужно требовать идеального названия.

Допустимые варианты:

```text
Тендер_1
Тендер_2
Тендер_3
```

Лучше, если сотрудник может указать завод:

```text
01_Протон_Пермь
02_ОДК_Сатурн
03_Казанский_вертолетный
```

Ещё лучше, если он добавит короткую тему:

```text
01_Протон_Пермь_метчики
02_ОДК_Сатурн_фрезы
03_КВЗ_калибры
```

Но это не обязательно для MVP.

---

# 5. Что должно лежать внутри папки тендера

Внутри каждой папки тендера сотрудник 1 должен сохранить всё, что удалось скачать:

- извещение;
- техническое задание;
- спецификацию;
- проект договора;
- архив документации;
- приложения;
- файлы Excel;
- файлы PDF;
- скриншоты или сохранённые страницы, если нужно;
- любые документы из закрытого источника.

---

# 6. Минимальный текстовый файл внутри папки

Не обязательно, но желательно добавить файл:

```text
info.txt
```

Минимальное содержание:

```text
Источник: zakupki.gov.ru / закрытый источник / другое
Ссылка: [ссылка, если есть]
Дата сохранения: 06.06.2026
Комментарий: [не обязательно]
```

Если сотрудник 1 совсем не должен ничего писать, этот файл можно не требовать.

---

# 7. Правило для сотрудника 1

Сотрудник 1 не обязан понимать, интересен тендер или нет.

Его задача:

```text
нашёл → скачал → положил → загрузил
```

Классификацией занимается сотрудник 2.

---

# 8. Что потом использует сотрудник 2

Сотрудник 2 берёт из облака:

- ссылку на папку;
- документы;
- название завода из документов;
- тип процедуры;
- даты;
- предмет закупки.

После этого он создаёт карточку в Odoo CRM.
