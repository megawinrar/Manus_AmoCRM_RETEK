# Карточка сделки amoCRM: тендерная возможность

## Принцип

В amoCRM основная сущность — **сделка**.

Сделка = тендерная возможность / СОЗ / реальный запрос котировок / архивная возможность.

Карточка сделки должна отвечать на 6 вопросов:

```text
Что это?
Почему это важно?
Кто отвечает?
Что следующее действие?
Когда дедлайн?
Что мешает движению?
```

## Название сделки

Формат:

```text
[Приоритет] [Тип ситуации] — [Заказчик] — [предмет / группа инструмента] — [ключевое действие]
```

Примеры:

```text
[Р2] СОЗ — Протон-ПМ — специнструмент — уточнить дату торгов
[Р1] Запрос котировок — Пермские моторы — сверла — срок 12.06
[Р3] Неясно — завод N — чертежи — проверить СОЗ или торги
```

## Обязательная логика

```text
Р1/Р2/Р3 + СОЗ → Сотрудник 2
Р1/Р2/Р3 + Запрос котировок / реальные торги → Сотрудник 3
Неясно → Сотрудник 2, может передать Сотруднику 3
Р4 → К архивированию / архив / база
```

## Следующее действие

В активной воронке сделка не может висеть без следующего действия.

Обязательные поля для живой сделки:

```text
Следующее действие
Дата следующего действия
Ответственный
```

Если действия нет, сделка должна получить:

```text
Дата возврата
или
Причина архивирования
```

и перейти в статус `К архивированию`.
