# Процесс MVP для amoCRM

## 1. Вход

```text
Сотрудник 1 загружает документы
→ LLM распознаёт
→ создаётся сделка amoCRM
→ сделка попадает в статус "LLM распознал"
```

## 2. Проверка

Сотрудник 2 проверяет карточку:

```text
тип ситуации
приоритет
направление
сроки
НМЦ
следующее действие
ответственного
```

## 3. Развилка

### СОЗ

```text
Р1/Р2/Р3 + СОЗ
→ Сотрудник 2
→ статус "СОЗ — звонок / уточнить дату"
→ задача: позвонить и узнать дату реального торга
```

Если дата реального торга известна:

```text
статус "СОЗ — ждём реальный торг"
дата возврата / задача на дату
```

### Реальные торги

```text
Р1/Р2/Р3 + Запрос котировок / реальные торги
→ Сотрудник 3
→ статус "Передано в закупку / расчёт"
```

### Неясно

```text
Неясно
→ Сотрудник 2
→ проверка
→ при необходимости передача Сотруднику 3
```

### Р4

```text
Р4 — Наблюдаем / В базу
→ статус "К архивированию"
→ архивное назначение по направлению
```

## 4. Закупка и КП

```text
Передано в закупку / расчёт
→ КП готовится
→ КП передано дилеру
```

## 5. Решение дилера

```text
Решение дилера = Выходим
→ Передано в производство
→ К архивированию с причиной "Вышли на торги" / итогом
```

```text
Решение дилера = Не выходим
→ К архивированию с причиной отказа
```

```text
Решение дилера = Нужно уточнить
→ возврат к Сотруднику 3 / КП готовится
```

## 6. Архивирование

Активная воронка заканчивается статусом:

```text
К архивированию
```

Дальше внешний микросервис:

```text
находит сделки в статусе "К архивированию"
проверяет обязательные поля
выбирает архивную воронку и статус
переносит сделку
создаёт примечание
создаёт будущую задачу, если нужна дата возврата
```
