# Логика архивов и переноса

## Принцип

Архив — это управляемая база будущей работы и аналитики, а не мусорная корзина.

## Активная воронка заканчивается буфером

```text
К архивированию
```

Карточки не должны долго жить в этом статусе.

## Кто переносит

Внешний микросервис, раз в сутки.

## Что проверяется перед переносом

```text
Тип ситуации
Приоритет
Направление
Подтип направления
Причина закрытия
Архивное назначение LLM
Архивное назначение итоговое
Дата возврата
Следующее действие
Ответственный
```

## Выбор архива

```text
СОЗ + ждём торги → Архив — СОЗ / Ждём реальные торги
СОЗ + нужен обзвон → Архив — СОЗ / К обзвону
SPEC-DRAWING → Архив — направления / Специнструмент по чертежам
HSS-STANDARD → Архив — направления / HSS ГОСТ
CARBIDE-STANDARD → Архив — направления / Твердосплав
DIAMOND-STANDARD → Архив — направления / Алмазный
OUT-OF-SCOPE → Архив — направления / Не наш ассортимент
Неясно → Архив — требуется проверка
```

## Дата возврата

У архивной карточки должно быть одно из двух:

```text
Причина, почему больше не трогаем
или
Дата, когда вернуться
```

Если нет ни причины, ни даты — это ошибка заполнения.

## Ежемесячная ревизия

Раз в месяц руководитель смотрит:

```text
карточки без даты возврата
карточки без причины закрытия
СОЗ, которые не вернулись в реальные торги
архив по направлениям
работу новичков по архиву
```
