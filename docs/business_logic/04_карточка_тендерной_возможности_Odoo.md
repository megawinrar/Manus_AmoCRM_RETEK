# Карточка тендерной возможности в amoCRM

> Файл сохранён под старым именем для совместимости архива. Актуальная логика — amoCRM.

## Основная сущность

**Сделка amoCRM = карточка тендерной возможности.**

## Название сделки

Рекомендуемый формат:

```text
[Р2] СОЗ — Протон-ПМ — специнструмент — уточнить дату торгов
```

или:

```text
[Р1] Запрос котировок — Пермские моторы — срок 12.06
```

```text
LLM summary

files_check
```

## Поля для контроля

```text
Дата создания

Возраст в текущем статусе
Просрочено следующее действие
Количество возвратов

```

## Принцип карточки

Карточка должна быстро отвечать:

```text
Что это?
Почему важно?
Кто отвечает?
Что следующее действие?
Когда дедлайн?
Что мешает?
Куда уйдёт в архив?
```
