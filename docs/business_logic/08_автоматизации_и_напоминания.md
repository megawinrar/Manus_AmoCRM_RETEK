# Автоматизации, напоминания и микросервис

## Что делает amoCRM

amoCRM используется как рабочая CRM:

```text
сделки
воронки
статусы
ответственные
задачи
примечания
поля
канбан
```

## Что делает внешний микросервис

Микросервис отвечает за логику, которую неудобно держать внутри CRM:

```text
создание сделки из результата LLM
маршрутизация
создание задач
контроль просрочек
перенос в архив
возврат из архива по дате
ежемесячные отчёты
```

## Расписание

```text
каждый час — контроль Р1/Р2 и просроченных задач
раз в сутки ночью — перенос в архив
раз в неделю — поиск зависших карточек
раз в месяц — ревизия архива и отчёт руководителю
```

## Перенос в архив

Микросервис ищет сделки:

```text
pipeline = Тендеры RETEK — активная работа
status = К архивированию
```

Проверяет поля:

```text
Тип ситуации
Приоритет
Направление
Причина закрытия
Архивное назначение LLM
Архивное назначение итоговое
Дата возврата
Следующее действие
```

Если поля заполнены:

```text
изменяет pipeline_id и status_id
добавляет примечание "Архивировано автоматически"
создаёт задачу на дату возврата, если требуется
```

Если поля не заполнены:

```text
возвращает / оставляет в статусе "Требует заполнения" или ставит задачу ответственному
```

## Возврат из архива

Если наступила `Дата возврата`, микросервис может:

```text
создать задачу ответственному
или
вернуть сделку в активную воронку в статус "Проверка Сотрудника 2"
```

Для СОЗ предпочтительно сначала задача на звонок, а не автоматический возврат в активную воронку.
