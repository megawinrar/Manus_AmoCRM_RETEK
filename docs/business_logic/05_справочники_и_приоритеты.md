# Справочники и приоритеты

## Приоритеты

Писать строго:

```text
Р1 — Срочно
Р2 — Быстрые Деньги
Р3 — Средние Деньги
Р4 — Наблюдаем / В базу
```

## Тип ситуации

```text
СОЗ
Запрос котировок / реальные торги
Неясно
Не наш ассортимент
```

## Маршрутизация

```text
Р1/Р2/Р3 + СОЗ → Сотрудник 2
Р1/Р2/Р3 + Запрос котировок / реальные торги → Сотрудник 3
Неясно → Сотрудник 2, возможна передача Сотруднику 3
Р4 → Наблюдаем / В базу / Архив
```

## Направления

```text
SPEC-DRAWING — специнструмент по чертежам / ТЗ
HSS-STANDARD — стандартный быстрорез / ГОСТ
CARBIDE-STANDARD — стандартный твердосплав
DIAMOND-STANDARD — алмазный инструмент без чертежа / стандартный
SOZ-DEVELOPMENT — СОЗ / развитие / будущий торг
REAL-TENDER — реальные торги / запрос котировок
OUT-OF-SCOPE — не наш ассортимент
ARCHIVE-LEAD — база / наблюдение / будущая проработка
```

## Подтипы SPEC-DRAWING

```text
твердосплав по чертежам
быстрорез по чертежам
алмазный по чертежам
прочий инструмент по ТЗ
инструмент по эскизу / образцу
```

## Причина закрытия / архивирования

```text
В базу / наблюдаем
Ждём реальные торги
Не наш ассортимент
Не успели
Нет КП
КП невозможно
Дилер отказался
Вышли на торги
Выиграли
Проиграли
Торги отменены
Дубль
Требуется повторный обзвон
```

```text
Архив — направления / Специнструмент по чертежам
Архив — направления / HSS ГОСТ
Архив — направления / Твердосплав
Архив — направления / Алмазный
Архив — направления / Не наш ассортимент
Архив — СОЗ / Ждём реальные торги
Архив — СОЗ / К обзвону
Архив — СОЗ / Повторить через 30 дней

Архив — требуется проверка
```
