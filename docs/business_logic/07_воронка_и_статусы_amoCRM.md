# Воронки и статусы amoCRM

## Главная активная воронка

```text
Тендеры RETEK — активная работа
```

Эта воронка — рабочий канбан. В ней живут только карточки, по которым есть действие.

## Статусы активной воронки

```text
1. LLM распознал
2. Проверка Сотрудника 2
3. СОЗ — звонок / уточнить дату
4. СОЗ — ждём реальный торг
5. Передано в закупку / расчёт
6. КП готовится
7. КП передано дилеру
8. Решение дилера
9. Передано в производство
10. К архивированию
```

## Не использовать старые статусы

Следующие статусы относятся к старой Odoo/Airtable-логике и не являются каноническими для PATCH5:

```text
Новое
Разобрано / классифицировано
Передал закупщику
В работе / ожидание торгов
Завершение / фиксация результата
Закрыто как отдельная рабочая колонка
```

В amoCRM они заменяются новой активной воронкой и архивными воронками.

## Роль статуса “К архивированию”

`К архивированию` — это буфер, а не настоящий архив.

Сделка должна находиться там короткое время, пока микросервис:

```text
проверяет поля
выбирает архивную воронку
переносит сделку через pipeline_id/status_id
создаёт примечание
создаёт задачу на возврат, если нужна
```

## Архивные воронки

### Архив — направления

Статусы:

```text
Специнструмент по чертежам
HSS / ГОСТ
Твердосплав
Алмазный
Не наш ассортимент
Дубли / мусор
Требуется проверка
```

### Архив — СОЗ / развитие

Статусы:

```text
СОЗ — ждём реальные торги
К обзвону
Повторить через 30 дней
Повторить через 90 дней
Интересный завод
Неактуально
```

### Архив — база / история

Можно добавить позже, если объём истории станет большим:

```text
Выиграли
Проиграли
Не участвуем
Торги отменены
Дубли / мусор
```

## Причина закрытия

Причина закрытия — это поле сделки, а не отдельная колонка на каждый случай.

```text
В базу / наблюдаем
Ждём реальные торги
Не наш ассортимент
Не успели
Нет КП
КП невозможно
Дилер отказался
Вышли на торги
Выиграли
Проиграли
Торги отменены
Дубль
```
