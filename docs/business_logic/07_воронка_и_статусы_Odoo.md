# Воронки и статусы amoCRM

> Файл сохранён под старым именем для совместимости архива. Актуальная логика — amoCRM.

## Активная воронка

Название:

```text
Тендеры RETEK — активная работа
```

Статусы:

```text
1. LLM распознал
2. Проверка Сотрудника 2
3. СОЗ — звонок / уточнить дату
4. СОЗ — ждём реальный торг
5. Передано в закупку / расчёт
6. КП готовится
7. КП передано дилеру
8. Решение дилера
9. Передано в производство
10. К архивированию
```

## Почему не делаем полноценный архив последней колонкой

Последняя колонка активной воронки не должна хранить все старые карточки.

Она является буфером:

```text
К архивированию
```

Дальше микросервис переносит сделку в архивную воронку.

## Архивные воронки

### Архив — направления

Статусы:

```text
Специнструмент по чертежам
HSS / ГОСТ
Твердосплав
Алмазный
Не наш ассортимент
Дубли / мусор
Требуется проверка
```

### Архив — СОЗ / развитие

Статусы:

```text
СОЗ — ждём реальные торги
К обзвону
Повторить через 30 дней
Повторить через 90 дней
Интересный завод
Неактуально
```

## Закрытые причины

Причина закрытия — поле сделки, а не отдельная колонка на каждый случай.

```text
В базу / наблюдаем
Ждём реальные торги
Не наш ассортимент
Не успели
Нет КП
КП невозможно
Дилер отказался
Вышли на торги
Выиграли
Проиграли
Торги отменены
Дубль
```

## Правило активной воронки

Если по карточке нет следующего действия, она не должна оставаться в активной воронке.

Она должна получить:

```text
Дата возврата
или
Причина архивирования
```
