# 15_ANTI_ERROR_CHECKLIST.md

# Контрольный список против ошибок классификации

Использовать перед каждым финальным ответом по новому тендеру.

## A. Сроки и контакты

- [ ] Срок подачи заявок найден и записан в `submission_deadline`.
- [ ] Если срок не найден, поле оставлено пустым, а не придумано.
- [ ] Контакты заказчика/организатора записаны: ФИО, email, телефон, роль.
- [ ] Если контактов нет, поля оставлены пустыми.

## B. Приоритет

- [ ] В `priority` стоит одно значение: `P1`, `P2`, `P3` или `P4`.
- [ ] Условные пояснения вынесены в `base_priority_without_close_deadline` или `classification_reason`.
- [ ] P1 поставлен только при горящем сроке / срочной необходимости КП.
- [ ] HSS без ГОСТ и с брендовой линейкой не занижен до P4 автоматически.

## C. Эквивалент / запреты

- [ ] Проверено, допускается ли эквивалент.
- [ ] ПП РФ №1875 не принят за запрет автоматически.
- [ ] Если есть исключение по подп. «и» / пункту 4 или 5 — это не запрет аналогов.
- [ ] Если написано "аналоги не допускаются" — аналог не подбирать.

## D. Термины

- [ ] Пластины не перепутаны с плашками.
- [ ] Борфрезы не перепутаны с обычными концевыми фрезами.
- [ ] Алмазный инструмент по чертежам не классифицирован как HSS/CARB/INSERT.

## E. Специальные маршруты

- [ ] KOBI + аналоги не допускаются → `INSERT-01`.
- [ ] Walter или другая сборная брендовая заявка одного производителя → `INSERT-03`, без secondary-компонентов.
- [ ] Алмазные фрезы/сверла/круги/фасочники по чертежам → `DIAM-01`.
- [ ] Борфрезы ВК10/ВК10-ХОМ → `CARB-06`.
- [ ] Твердосплавные сверла/микросверла без чертежа и без жёсткого бренда → `CARB-02`.
- [ ] Брендовые HSS/HSSCo/HSSE-PM фрезы без ГОСТ → `HSS-05`, при широком составе `HSS-07` secondary.

## F. Смешанные закупки

- [ ] Если закупка многолотовая, каждый лот классифицирован отдельно.
- [ ] Если лот смешанный, primary выбран по правилу/НМЦ/коммерческой массе, а не автоматически по количеству строк.
- [ ] Если сработал специальный общий код, лот не дробится на вторичные маршруты без необходимости.

## G. Обучающие файлы

- [ ] Реальные сырые позиции сохранены в `12_тренировка_LLM_классификатора.md`.
- [ ] Машинный пример добавлен в `13_llm_training_examples.jsonl`.
- [ ] Новое правило добавлено в `06_глоссарий_и_правила_классификации_LLM.md`.
- [ ] Исправление или новый пример отражены в `99_CHANGELOG.md`.

## H. Полнота чтения файлов

- [ ] Перед финальной классификацией изучены все файлы комплекта.
- [ ] Если файл не открылся / не распарсился / прочитан частично — это явно указано в ответе.
- [ ] Если хотя бы один файл не прочитан полностью, `classification_status = preliminary`.
- [ ] Нельзя финально подтверждать `equivalent_allowed`, `platform`, `submission_deadline`, `nmc`, `brand_lock`, если соответствующий файл не прочитан.
- [ ] Для `.xls/.xlsx/.doc/.pdf` проверять не только расчёт НМЦ, но и ТЗ, извещение, проект договора, форму КП.

Обязательный блок в каждом ответе:

```yaml
files_check:
  all_files_received:
  all_files_read:
  unread_files:
  partially_read_files:
  classification_status:
```

Стоп-слова для проверки эквивалента / бренд-лока:

```text
"эквивалент не допускается"
"поставка эквивалентной продукции не допускается"
"недопустима замена продукции на эквивалент"
"аналоги не допускаются"
"без эквивалента"
"техническая политика заказчика"
"марка указана в технической политике"
"ЕПОЗ 10.3.6(5)"
"продукция марки"
"только оригинал"
```

## I. Бизнес-стоп-фильтр: пластины и державки

- [ ] Перед маршрутизацией проверено, не доминируют ли в лоте пластины, державки, корпуса под СМП, опорные пластины, втулки, рычаги, винты.
- [ ] Если такие позиции доминируют, итоговое решение: `OUT_OF_SCOPE / не наш ассортимент / не участвуем`.
- [ ] `INSERT-01/INSERT-02/INSERT-03` в таком случае сохранён только как `technical_code_for_context_only`, а не как рабочий маршрут.
- [ ] КП не запрашивается по лотам, где основная масса — пластины/державки/СМП-оснастка.
- [ ] Срочный срок и известный бренд Dormer-Pramet / Pramet / Walter / Sandvik / Iscar / Seco не повышают такой лот до `P1`.
- [ ] Минорные HSS-позиции внутри такого лота не меняют решение, если коммерческая масса остаётся вне ассортимента.

## J. HSS-зуборезный инструмент

- [ ] Долбяки по ГОСТ 9323-79 классифицированы как `HSS-08`, не `HSS-01`.
- [ ] Червячные фрезы по ГОСТ 9324-2015 классифицированы как `HSS-08`, не `HSS-01`.
- [ ] `HSS-07` использован только как контекст редкого ГОСТ/точного исполнения, если более точный код `HSS-08` уже сработал.
