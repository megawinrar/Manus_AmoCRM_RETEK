# LEGACY OLD LOGIC

Эта папка содержит файлы старой логики Odoo/Airtable и старые обучающие материалы.

Они сохранены для истории, но **не являются каноническими** для текущей реализации amoCRM.

Для актуальной логики использовать:

```text
00_START_контекст_для_новой_сессии.md
01_роли_и_ответственность.md
02_процесс_MVP.md
04_карточка_сделки_amoCRM.md
07_воронка_и_статусы_amoCRM.md
12_LLM_CLASSIFIER_AMOCRM_RULES_CANONICAL.md
16_AMOCRM_ТЗ_логика_и_поля.md
17_ARCHIVE_логика_архивов_и_переноса.md
18_SCALE_масштабирование_команд_и_WIP.md
19_MICROSERVICE_amoCRM_API_архиватор.md
```

Старые поля `crm_status` вида `Разобрано / классифицировано`, `Передал закупщику`, `В работе / ожидание торгов` не должны попадать в новую реализацию.
