# Регламенты сотрудников

## Сотрудник 2 / продажник

Ежедневная очередь:

```text
Проверка Сотрудника 2
СОЗ — звонок / уточнить дату
Неясно
Карточки без следующего действия
Архив — к обзвону
```

Правило работы:

```text
каждая карточка должна иметь следующее действие и дату
если действия нет — архивировать или поставить дату возврата
```

## Сотрудник 3 / закупщик

Ежедневная очередь:

```text
Передано в закупку / расчёт
КП готовится
КП передано дилеру
Нужно уточнить после решения дилера
```

## Руководитель

Контроль:

```text
Р1 / Р2
Просроченные задачи
Неясно
Карточки в статусе К архивированию больше 24 часов
Архив — требуется проверка
нагрузка по сотрудникам
```

## Новые сотрудники

Новый сотрудник не получает всю CRM. Он получает очередь:

```text
СОЗ к обзвону
Р3 к проверке
архив по направлению
карточки без следующего действия
```

## WIP-лимиты

Ориентиры для пары продажник + закупщик:

```text
Р1 одновременно: 3–5
Р2 одновременно: 7–12
Р3 одновременно: 15–25
СОЗ в ожидании / обзвоне: 30–50
Р4 в активной воронке: не держать
```

Если активных карточек больше 80 на пару, нужна чистка, архивирование, фильтры или расширение команды.
