# Глоссарий и правила классификации LLM

## Режим

LOCKED_NO_TRAINING сохраняется: LLM не добавляет новые правила самовольно. Если случай неизвестный или конфликтный — `manager_question_required: true`.

## Главная классификация

LLM должен определить:

```text
Тип ситуации
Приоритет
Направление
Подтип направления
Маршрут
Ответственного
Нужно ли КП / расчёт
Архивное назначение LLM
Уверенность
```

## Тип ситуации важнее приоритета

Сначала определить тип ситуации:

```text
СОЗ / сбор КП / предварительная процедура
или
Запрос котировок / реальные торги
```

Потом применять приоритет.

## Правило маршрутизации

```text
Если Р1/Р2/Р3 + СОЗ → Сотрудник 2
Если Р1/Р2/Р3 + Запрос котировок / реальные торги → Сотрудник 3
Если Неясно → Сотрудник 2, возможна передача Сотруднику 3
Если Р4 → Архив / база / наблюдение
```

## Направление SPEC-DRAWING

В одно крупное направление объединяются:

```text
специнструмент из твердосплава по чертежам
специнструмент из быстрореза по чертежам
алмазный инструмент по чертежам
любой инструмент по ТЗ / эскизу / образцу
```

Условие: есть чертёж, ТЗ, эскиз, образец, нестандартное исполнение, размеры/геометрия под заказ.

Для CRM это один процесс: нужна техническая оценка, расчёт, производство и сроки.

## Алмазный инструмент

```text
если алмазный инструмент по чертежу → SPEC-DRAWING / подтип: алмазный по чертежам
если стандартный алмазный без чертежа → DIAMOND-STANDARD
```

## OUT_OF_SCOPE

Лоты, доминируемые пластинами, державками, корпусами под СМП, винтами, втулками, рычагами, комплектующими пластинчатого инструмента Pramet/Dormer-Pramet/Walter/Sandvik/Iscar/Seco, не должны уходить в работу как INSERT-03. Бизнес-решение: OUT_OF_SCOPE / не наш ассортимент.

## Архивное назначение LLM

LLM должен предложить архив:

```text
если СОЗ и ждём торги → Архив — СОЗ / Ждём реальные торги
если СОЗ к обзвону → Архив — СОЗ / К обзвону
если SPEC-DRAWING → Архив — направления / Специнструмент по чертежам
если Р4 по интересному направлению → Архив — направления / соответствующее направление
если OUT_OF_SCOPE → Архив — направления / Не наш ассортимент
если неясно → Архив — требуется проверка
```

## Обязательный YAML-блок при классификации

```yaml
files_check:
  archive_received: true/false
  files_total: <number>
  files_read: <number>
  unread_files: []
  partially_read_files: []
  classification_status: final/preliminary

crm_routing:
  type_situation: СОЗ | Запрос котировок / реальные торги | Неясно | Не наш ассортимент
  priority: Р1 — Срочно | Р2 — Быстрые Деньги | Р3 — Средние Деньги | Р4 — Наблюдаем / В базу
  direction: SPEC-DRAWING | HSS-STANDARD | CARBIDE-STANDARD | DIAMOND-STANDARD | SOZ-DEVELOPMENT | REAL-TENDER | OUT-OF-SCOPE | ARCHIVE-LEAD
  subtype: <string>
  responsible_role: Сотрудник 2 | Сотрудник 3 | Руководитель
  next_action: <string>
  archive_destination_llm: <string>
  manager_question_required: true/false
```
