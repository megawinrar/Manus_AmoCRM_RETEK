# RETEK amoCRM Integration

Микросервис и скрипты интеграции для автоматизации бизнес-процессов тендерной компании RETEK в amoCRM.

## Архитектура и логика работы

Проект реализует автоматизацию тендерного отдела на базе amoCRM с использованием Внешней интеграции (API).

Основные компоненты:
1. **Настройка amoCRM:** Воронки, статусы, пользовательские поля и права доступа.
2. **Микросервис-архиватор:** Автоматический перенос сделок из активной воронки («К архивированию») в соответствующие архивные воронки на основе направления и логики СОЗ.
3. **LLM-классификатор:** Интеграция с ИИ для первичного разбора тендерной документации и маршрутизации (взаимодействует с API amoCRM).

## Структура репозитория

- `docs/` — документация по процессам, ролям и настройкам amoCRM.
- `src/` — исходный код микросервиса (Node.js / Python).
- `config/` — конфигурационные файлы и маппинги полей.
- `scripts/` — вспомогательные скрипты для развёртывания полей и воронок.

## Требования

- Аккаунт amoCRM
- Внешняя интеграция amoCRM (client_id, client_secret, redirect_uri)
- Node.js 18+ или Python 3.10+ (в зависимости от выбранного стека микросервиса)

## Настройка Внешней интеграции

1. Перейдите в amoCRM -> Настройки -> Интеграции -> Создать интеграцию -> Внешняя интеграция.
2. Укажите необходимые права (Сделки, Контакты, Компании).
3. Получите ключи и добавьте их в `.env` файл микросервиса.
